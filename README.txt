CARLO.EXE — ONE-PAGE PERSONAL WEBSITE

MAIN ENTRY
- index.html is the one-page personal portfolio for the HCI Get My Vibe.
- About, Interests, Skills, and Explore Lab are sections on the same page.
- Explore Lab cards open each interactive experience in an accessible overlay; the visitor returns to index.html when closing it.

FEATURE FILES
- byte.html + byte.js: animated robot pet
- skill-tree.html + skill-tree.js: Skill Tree RPG
- personality.html + personality.css + personality.js: personality quiz
- secret.html + secret.js: hidden clue progress and unlock message (clues are discoverable across index.html)
- terminal.html + terminal.js: safe pretend terminal
- challenge.html + challenge.js: Get My Vibe
- style.css, main.js, hub.js: shared portfolio design, interactions, and theme
- profile-photo.jpg: profile portrait used on the main page

RUN LOCALLY
Keep all files in the same folder. Open index.html with VS Code Live Server. Click Explore Lab cards to launch an experience, then close the overlay to return to the same page.

GITHUB PAGES
Upload the full folder and enable GitHub Pages. No backend or build step is required. Feature pages are loaded locally inside the overlay. Local storage remains browser/device-specific and does not sync between visitors.

HCI NOTE
The main browsing experience stays on one personal portfolio page. Interactive experiences open only when the visitor chooses them; they are not forced to wait or stay. Three Secret File clues are hidden in the profile card, About quote, and closing stamp on index.html.
